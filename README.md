# Mary Hardy – Personal Portfolio Website

![Portfolio website screenshot](https://github.com/samin7654/portfolio-1/blob/main/Screenshot%202026-10-12%20185043.png)

A responsive personal portfolio website that presents a web designer and developer's skills, education, experience and contact details in a clean one-page layout.

## 🔗 Links

- **Live Demo:** https://samin7654.github.io/portfolio-1/
- **GitHub Repository:** https://github.com/samin7654/portfolio-1

## 📖 Overview

This project is a front-end portfolio website built to introduce a designer and developer to potential clients and employers. Visitors can learn about the person, see the skills and technologies they work with, read a summary of their resume, browse a gallery, and get in touch.

## ✨ Features

- Navigation bar with Portfolio, Blog and Hire me links
- Hero section with introduction, **Download CV** and **Contact** buttons
- **About Me** section with personal details
- **What I Do** section with skill cards (JavaScript, React/Angular/Vue, Node.js, Python/Django)
- **Resume summary** with education and work experience timelines
- Image gallery ("My Amazing Section")
- **Let's Connect** section with social media icons and a contact form
- Responsive design for desktop and mobile

## 🛠️ Technologies Used

- **HTML5** – structure
- **CSS3** – styling, Flexbox/Grid, responsive layout
- **GitHub Pages** – hosting

## 📦 Dependencies

No external libraries or frameworks are required. The project uses plain HTML and CSS, so there is nothing to install.

## 🚀 Run Locally

1. Clone the repository:
```bash
   git clone https://github.com/samin7654/portfolio-1.git
```
2. Go to the project folder:
```bash
   cd portfolio-1
```
3. Open `index.html` in your browser (double-click it, or use the VS Code **Live Server** extension).
